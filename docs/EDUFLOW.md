# EduFlow 제품 로드맵

## 서비스명

**EduFlow**

## 한 줄 소개

학생 흐름 데이터를 기반으로 교육 운영을 자동화하는 AI Workflow Platform

## 비전

교육 현장의 학생 데이터는 카카오톡, 개인 메모, 상담 기록, 시험지 등에 흩어져 있습니다. EduFlow는 이를 **하나의 흐름**으로 연결해 학습·성장 과정을 기록 기반으로 관리합니다.

단순 저장이 아니라, **데이터 기반 교육 운영 자동화**를 목표로 합니다.

| 인사이트 | 기록 배지, 관리 필요 학생, 대시보드·반별 흐름 |

## 기능 상세 (요구사항 메모)

### 1. AI 학부모 상담 Agent

- **위치:** 학부모 포털
- **조회:** 수업 기록, 숙제, 점수, 상담 카드, 단원, 보강, 강사 메모
- **원칙:** 데이터·근거 기반, 판단 최소화, 기록 중심

### 2. 위험 학생 자동 감지

- 탐지: 점수 하락, 숙제 미제출 증가, 반복 오답/태그, 단원 정체, 상담 후 개선 없음
- 표시: 상담 권장 · 보강 권장 · 주의 필요 · 회복 중

### 3. AI 상담 준비 브리핑

- 학생별 30초 요약 (단원·숙제율·보강·상담 이력·권장 대화 포인트)

### 4. Student Digital Twin

- 강점 / 약점 / 반복 패턴 / 최근 변화 / 위험 요소 (기록에서만 추론)

### 5–6. Google 연동

- Login · Gmail+PDF — Supabase Auth 확장 또는 별도 OAuth 앱 필요 (캘린더는 앱 내 시간표만 사용)

### 8. Dashboard Action Center

- 상단 「오늘 해야 할 일」: 클릭 시 해당 화면으로 이동

## 장기 확장

```
수학학원 (현재)
  → 영어·국어·입시·코딩·예체능
  → 교육 AI 운영 인프라
```

EduFlow는 단순 학원 ERP가 아니라, **기억 기반 운영 → 데이터 기반 운영** 전환을 돕는 플랫폼을 지향합니다.
