# ADR-006: AI는 Dashboard 주인공이 아님

- **Status:** Accepted
- **Context:** 과거 KPI·Agent Center 과밀. 제품 방향: **운영 60 · AI 25 · 상담 15**.
- **Decision:** Dashboard는 운영 체크리스트·시간표·KPI 우선. AI는 Assistant Layer(추천·요약·상담 준비)로 Dashboard 25% 비중.
- **Consequences:** AgentArchitecturePanel·튜토리얼 배너 임의 재도입 금지.
- **Alternatives:** AI-first Dashboard — 원장 일일 운영 UX 희석.
