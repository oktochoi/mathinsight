# 전체 개선 필요 목록

경쟁사 조사 + 현재 코드베이스 분석 기반. 우선순위 순.

> **전제:** 학부모·학생은 우리 앱(Flutter WebView)을 설치해서 사용.
> 알림은 앱 푸시(FCM)로 전달. 출결 알림도 동일.
> 경쟁사가 외부 메시지 채널에 의존하는 것과 달리 자체 앱 채널을 보유한 것이 강점.

---

## 1. UI/UX — 통일감 / 레이아웃

### 로그인 화면
- 원장/교사 로그인, 학부모 로그인, 학생 로그인이 3개 다 다르게 생김
- 같은 서비스인데 들어가는 입구부터 브랜드 느낌이 다름
- 로고, 폰트 크기, 버튼 모양, 배경색 통일 필요
- `AuthFormCard` 기반으로 일부 통일됨 — 배경·헤더 문구는 추가 정리 필요

### 디자인 토큰 3개 혼용
- 원장/교사: `--app-*` CSS 변수
- 학부모: `parent-portal` scoped `--portal-*` (→ `--app-*` 브릿지 적용됨)
- 학생: `student-portal` scoped `--portal-*` / `--student-*` (→ `--app-*` 브릿지 적용됨)
- Tailwind `stone-*` / `sky-*` 직접 사용은 점진적 `--portal-*` 치환 필요

### 데스크탑 레이아웃
- ~~1440px 이상 모니터에서 콘텐츠가 중앙 좁은 컬럼에만 몰림~~ ✅ `AppShell`·대시보드 `max-w-7xl` / `xl:max-w-[1440px]` 확장
- 스케줄·수납 등 개별 화면은 추가 확장 여지 있음

### 선생님과 원장 화면 구분 불명확
- 원장이 볼 화면과 강사가 볼 화면이 거의 똑같음
- 원장: 매출·재등록·원생 현황 중심
- 강사: 오늘 수업·숙제 채점·개별 학생 중심
- 지금은 같은 대시보드를 공유 → 강사한테 불필요한 정보가 너무 많음

### 빈 상태(Empty State)
- 신규 학원이 처음 들어오면 모든 화면이 텅 빔
- "학생을 추가해보세요", "첫 수업을 등록해보세요" 같은 온보딩 가이드 없음
- 텅 빈 화면은 서비스가 망한 것처럼 보임

### 학생 정보 화면
- 현재: 이름·학년·수강반 정도만 보임
- 없는 것: 총 누적 수업 시간, 과목별 평균 성적, 출석률 %, 최근 3개월 추세 그래프
- 학부모한테 보여주기 창피한 수준의 정보량

### 모바일 (앱 기준)
- 원장·강사 화면이 모바일에서 거의 안 됨 (테이블, 긴 폼 등)
- 앱으로 접근하는데 터치 최적화가 안 돼 있음
- 수업 확인, 출결 처리, 메모 입력이 모바일에서 불편함

## 3. 핵심 기능 누락

### 결제 시스템 (가장 큰 구멍)
- 현재 결제는 목업 — 실제 돈이 오가는 기능 없음 (`tossProvider` 스텁)
- 없는 것들:
  - 카드 결제 (PG 연동 — 토스페이먼츠, KCP 등)
  - 계좌이체 결제 링크 앱 푸시로 발송
  - 분할 납부 설정
  - 원장이 현금/계좌이체 수납 수동 기록 (완납 처리는 있음)
  - 법정 교습비 영수증 출력 (학원법 의무)
  - 현금영수증 발행

### 선생님 ↔ 학부모 1:1 채팅
- 채팅 UI·FAB는 있으나 운영 완성도는 미흡
- 앱 안에서 선생님·원장과 채팅이 되면 앱 사용 이유가 생김

### 학원 운영 기능
- ~~학원 공지 게시판~~ ✅ (발행 + 푸시)
- 선생님 급여 계산 없음
- 반 정원 관리 없음
- 학원 일정(방학·휴원) 관리 없음
- 수강료 단가 템플릿 없음

### 학부모 상담 예약
- 학부모가 상담 시간을 앱에서 직접 예약할 수 없음

- 출석·숙제·성적·공지·수납 요약 등 점진적 보강 중 (`ParentTodaySummary` 등)
