# Google Whisk & ezgif — 정확한 프롬프트와 설정값

## Phase 1: Google Whisk

URL: `labs.google/fx/tools/whisk`

절차:
1. 사용자의 사진/컨셉 이미지를 Whisk에 업로드하도록 안내
2. 아래 스타일 프롬프트를 프로젝트/브랜드에 맞게 조정해 제안 (원본 예시 그대로 복붙하지 말고, 실제 톤앤매너에 맞춰 색상·분위기 문구를 바꿔 제시한다):

```
시네마틱 — 하이 컨트라스트 듀얼톤 조명, [브랜드 컬러 A] + [브랜드 컬러 B].
분위기: 드라마틱하고 프리미엄, 모던. 무비 포스터 같은 히어로 섹션을 연상.
키 라이트: 강한 [따뜻한/차가운] 톤. 필 라이트: 반대쪽에서 은은하게.
배경: 위쪽은 어둡고, 아래로 갈수록 [브랜드 컬러]로 페이드.
피사체: 클로즈업, 정면 또는 약간 위를 바라봄. 텍스트가 들어갈 좌우 여백 확보.
마감: 매끄럽고 전문적인 톤.
```

3. 프레임을 선택한 뒤 Whisk의 Animate 버튼으로 애니메이션화. 애니메이션 프롬프트 예시:

```
부드럽고 시네마틱한 3D 패럴랙스 전환 — 느린 줌, 은은한 광원 변화, 미세한 파티클.
```

프로 팁: 4~6개 프레임을 생성해 가장 임팩트 있는 것을 고른 뒤 애니메이션화하면 결과물 품질이 크게 올라간다.

**여기서 멈추고 사용자 확인을 기다린다.**

## Phase 2: ezgif

URL: `ezgif.com/video-to-webp`

설정값:
| 항목 | 값 |
|------|-----|
| Resolution | Original |
| FPS | 15 (또는 소스 영상과 가장 가까운 값) |
| Quality | 85 |

절차:
1. Whisk에서 만든 애니메이션(영상)을 업로드해 위 설정으로 WebP 변환
2. Split 버튼으로 개별 프레임 이미지로 분리
3. 생성된 ZIP 다운로드 후 압축 해제
4. 프레임 폴더를 사용자와 합의한 경로(예: `public/sequence/hero/`)에 배치하도록 요청

**중요**: 원본 Castimedia 가이드는 폴더명을 반드시 `sequence`로 고정하라고 하지만(Antigravity가 하드코딩된 이름을 참조하기 때문), 이 프로젝트는 Claude Code가 직접 컴포넌트를 작성하므로 폴더명을 자유롭게 정할 수 있다 — 단, Phase 3에서 작성하는 `ScrollyCanvas`의 `framePath` 인자와 실제 폴더 경로가 정확히 일치해야 한다는 원칙은 동일하게 적용된다. 경로 불일치가 이 워크플로우에서 가장 흔한 실패 지점이다.

**여기서 멈추고 사용자 확인 + Glob 검증을 마친 뒤에만 Phase 3으로 진행한다.**
